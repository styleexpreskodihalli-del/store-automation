# STore Automation Mobile MVP

This is the mobile-first PWA shell for the Flow Salon pilot.

Included:
- Dashboard
- Daily AI marketing review workflow
- Google Review Assistant
- Leads and bookings
- Salon profile
- Installable PWA structure (manifest + service worker)

Production integrations still required:
- Authentication / multi-tenant backend
- Google Business Profile API for reading/responding to reviews
- Meta APIs for Instagram/Facebook publishing
- WhatsApp Business Platform
- Booking database/API
- AI content generation service
- Analytics/revenue attribution
